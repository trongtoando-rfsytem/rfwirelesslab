Array Factor của anten mảng ULA

Bài học mở đầu về pha kích thích và điều khiển hướng búp sóng của mảng tuyến tính.

1. Array Factor là gì?

Array Factor (AF) mô tả phép cộng trường từ các phần tử trong mảng anten theo từng hướng quan sát. Trong mô hình lý tưởng, AF chi phối hướng búp chính, búp phụ và các điểm triệt. Pattern bức xạ tổng còn phụ thuộc đặc tính từng phần tử anten.

2. Mô hình ULA

Với mảng tuyến tính đồng nhất gồm N phần tử cách đều d, gọi θ là góc đo từ hướng broadside (vuông góc trục mảng). Để quét búp tới góc θ₀, pha kích thích phần tử thứ n có thể chọn βₙ = −2πn(d/λ)sinθ₀.

AF(θ) = | (1/N) Σₙ₌₀ᴺ⁻¹ exp(j 2πn(d/λ)[sinθ − sinθ₀]) |

3. Tham số cần quan tâm

  • N: Số phần tử tăng với khoảng cách d không đổi thường giúp thu hẹp búp chính.
  • d/λ: Ảnh hưởng độ rộng búp và nguy cơ xuất hiện grating lobes.
  • θ₀: Góc điều hướng búp, thiết lập thông qua pha kích thích.
  • HPBW: Độ rộng góc giữa hai điểm tại mức công suất giảm 3,0103 dB so với cực đại.

4. Thực hành

So sánh N = 4, 8, 16 với d/λ = 0,5 và θ₀ = 0°. Quan sát sự thay đổi HPBW. Sau đó quét tới θ₀ = 45° để thấy độ rộng búp thay đổi theo tọa độ góc.

Mở công cụ Array Factor ↗
Mô hình này bỏ qua coupling, pattern phần tử, sai lệch biên độ/pha và sai số hiệu chuẩn. Không dùng AF chuẩn hóa để kết luận trực tiếp gain hoặc EIRP của sản phẩm.

1. What is the Array Factor?

The Array Factor (AF) describes the directional superposition of fields contributed by the elements of an antenna array. In an idealized model, AF controls the main beam, sidelobes, and nulls. The complete radiation pattern also depends on each element's pattern.

2. Uniform Linear Array (ULA)

Consider N equally spaced elements separated by d. Let θ be measured from broadside, normal to the array axis. To steer towards θ₀, the excitation phase for element n may be βₙ = −2πn(d/λ)sinθ₀.

AF(θ) = | (1/N) Σₙ₌₀ᴺ⁻¹ exp(j 2πn(d/λ)[sinθ − sinθ₀]) |

3. Key parameters

  • N: Increasing the element count at fixed spacing generally narrows the main beam.
  • d/λ: Influences beamwidth and the risk of grating lobes.
  • θ₀: Steering angle set by the excitation phases.
  • HPBW: Angular separation of the two half-power points, at −3.0103 dB relative to peak.

4. Practical exercise

Compare N = 4, 8, and 16 with d/λ = 0.5 at θ₀ = 0°. Observe how HPBW changes. Then steer to θ₀ = 45° and examine the shape in angular coordinates.

1. 什么是阵列因子？

阵列因子（Array Factor，AF）描述天线阵列各阵元在指定方向上的电磁场叠加。在理想模型中，AF 决定主波束、旁瓣和零点；完整辐射方向图还取决于各阵元的方向图。

2. 均匀线阵（ULA）模型

考虑包含 N 个等间距阵元的线阵，阵元间距为 d，角度 θ 从阵列法向（broadside）测量。为了将主波束指向 θ₀，可以设置第 n 个阵元的激励相位为 βₙ = −2πn(d/λ)sinθ₀。

AF(θ) = | (1/N) Σₙ₌₀ᴺ⁻¹ exp(j 2πn(d/λ)[sinθ − sinθ₀]) |

3. 关键参数

  • N： 阵元间距不变时，增大阵元数通常能使主波束变窄。
  • d/λ： 影响波束宽度及栅瓣出现的风险。
  • θ₀： 通过各阵元激励相位设置的波束扫描角。
  • HPBW： 相对于峰值下降 3.0103 dB 的两个半功率点之间的角度。

4. 动手实验

在 d/λ = 0.5、θ₀ = 0° 的条件下，对比 N = 4、8 和 16 的 HPBW，再将波束扫描到 θ₀ = 45°，观察角度坐标中波束宽度的变化。
