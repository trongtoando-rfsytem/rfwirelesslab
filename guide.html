Cách thêm bài học, PDF và công cụ

Không cần thuê thêm hosting hoặc cài backend. Các thay đổi đều thực hiện từ GitHub repository của bạn.

Trang này chỉ hướng dẫn quản trị. Khách truy cập không thể tự upload tài liệu lên GitHub Pages.

1. Upload tệp

Trong GitHub, mở docs/ (PDF), lessons/ (bài HTML) hoặc tools/ (công cụ HTML). Chọn Add file → Upload files, sau đó Commit changes.

Mở repository GitHub

2. Cập nhật danh sách

Mở assets/content.js, nhấn biểu tượng bút chì, thêm một đối tượng vào lessons, tools hoặc resources. Điền đủ vi, en và zh.

Chỉnh sửa danh mục content.js

Ví dụ thêm một PDF

{
  id: 'beamforming-intro',
  category: 'beamforming',
  format: 'PDF',
  href: 'docs/beamforming-intro.pdf',
  title: {
    vi: 'Bài giảng Beamforming',
    en: 'Beamforming Lecture',
    zh: '波束赋形课程'
  },
  description: {
    vi: 'Giới thiệu Beamforming.',
    en: 'Introduction to beamforming.',
    zh: '波束赋形入门。'
  },
  tags: ['beamforming', 'MIMO']
},

3. Chờ xuất bản

Sau khi nhấn Commit changes, mở tab Actions để theo dõi quá trình xuất bản. Tải lại rfwirelesslab.com khi deployment thành công.

GitHub Actions ↗

Ghi nhớ

  • Tên file không dấu và không khoảng trắng, ví dụ: docs/beamforming-intro.pdf.
  • Liên kết nội bộ phải khớp chính xác tên file, kể cả chữ hoa và chữ thường.
  • Các bài PDF giữ nguyên ngôn ngữ bên trong; bộ chuyển ngôn ngữ chỉ thay đổi phần giao diện và metadata.
  • Công cụ HTML bên ngoài không tự dịch; cần dùng assets/i18n.js hoặc tạo bản dịch trong từng công cụ.
